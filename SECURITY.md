# Security Policy

If you discover a security vulnerability in this project, please follow these steps to report it responsibly.

1. Do NOT create a public issue. Public disclosure may put users at risk.
2. Send a private email to the maintainer: calixtusnwaeke@gmail.com
   - Subject: [SECURITY] Short description
   - Body: Affected component, versions, steps to reproduce, impact, suggested fix
3. If the vulnerability is sensitive, encrypt your message using the maintainer's PGP key. Contact the maintainer for the key fingerprint if needed.
4. The maintainer will acknowledge receipt within 72 hours and coordinate a fix and disclosure timeline.

Supported versions

- Security fixes will be applied to the `main` branch and backported to any actively supported release branches.

Disclosure timeline

- Coordinated disclosure will generally follow this sequence: acknowledgement -> patch -> CVE (if applicable) -> public advisory.

Contact: calixtusnwaeke@gmail.com
